# Detalles para vos — Prototipo web

Prototipo de la página de **Detalles para vos** (personalización en Costa Rica: bordado, vinil textil, DTF, sublimación y grabado láser).

## Estructura
- `index.html` — página estática (HTML + CSS, sin dependencias). Se adapta a escritorio, tablet y celular.
- `img/` — fotos de producto y logo (`logo-white.png` / `logo.png`).
- Fuentes: Righteous + Poppins (Google Fonts).
